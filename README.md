This project analyzes and forecasts the monthly closing stock price of Yes Bank, an Indian financial institution whose stock experienced significant volatility following the 2018 fraud case involving former CEO Rana Kapoor. Using monthly Open, High, Low, and Close prices from July 2005 onward, the goal was to understand the price behavior around this event and evaluate whether time-series and machine learning models could reliably predict closing prices.

The exploratory phase examined distributions, trends, and the relationship between price fields through histograms, line plots, and a candlestick chart. This confirmed a relatively stable growth phase from 2005–2017, followed by a sharp decline and increased volatility from 2018 onward — consistent with the fraud case's market impact. Three hypothesis tests were then used to formalize these observations: a Pearson correlation confirming a strong relationship between one month's closing price and the next month's opening price, a two-sample t-test showing a statistically significant shift in mean closing price before versus after the crash, and a one-tailed test confirming the normalized closing position was significantly higher during the growth era than after.

For modeling, the series was tested for stationarity using the Augmented Dickey-Fuller test, which indicated differencing was needed before fitting ARIMA-family models. Three models were built: ARIMA, SARIMAX (to test for 12-month seasonality), and XGBoost Regressor using engineered lag and rolling-average features. Each was tuned via grid search and evaluated primarily on Mean Absolute Error, using a chronological (non-shuffled) train/test split appropriate for time-series data.

Initial results showed XGBoost achieving the lowest MAE, followed by ARIMA, with SARIMAX performing worst — likely because the assumed seasonal component wasn't strongly supported by the series' actual seasonal decomposition, and the added seasonal differencing may have amplified noise on a relatively small (~185-row) monthly dataset.

Key caveats surfaced during review, which should be addressed before treating these results as final: the XGBoost feature set included same-period High/Low and an Open−Close difference term, both of which leak information not actually available at prediction time, meaning its reported advantage is likely overstated; and hyperparameter tuning for ARIMA/SARIMAX was scored against the test set itself rather than a separate validation split, which biases the reported error downward. Correcting both issues — restricting features to information available before the month closes, and separating tuning from final evaluation — is the natural next step, along with residual diagnostics (e.g., Ljung-Box) to validate the ARIMA/SARIMAX fits more rigorously.
